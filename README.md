## 🚀 Qué construyo

- **Plataformas SaaS multi-inquilino** — facturación, suscripciones, provisión automática, multi-marca / white-label.
- **Sistemas ERP y de gestión empresarial** — integración con SAINT + SQL Server (facturación, inventario, conciliación, CxP/CxC, nómina), gestión documental en .NET 8.
- **Fintech / cobros** — crypto (Binance Pay) y pagos locales LATAM, con panel, conciliación automática, libro mayor y bots.
- **Streaming / IPTV a gran escala** — infraestructura multi-servidor, resellers, transcoding y sincronización distribuida.
- **Motores de tienda / e-commerce digital** — catálogo, billetera, gift cards, inventario, entrega automática (PHP + Laravel).
- **Apps PWA instalables** — offline, service workers, push notifications.
- **Automatización, bots (Telegram/WhatsApp) y agentes de IA**.
- **Infraestructura** — administración de flotas de servidores, Docker, DNS, backups y despliegues.
